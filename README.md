# 🌸♾️ 3D Spatial UI Component Library

**Transform traditional web UI controls into immersive 3D spatial interfaces**

## 🎯 Vision

This library transforms web UI controls into 3D spatial interfaces that support:
- 🎨 **Generative/Adaptive UI** - AI-driven layout adaptation
- 🗣️👆 **Multimodality** - Voice, gesture, and spatial interaction
- ♿ **Accessible Calm Design** - WCAG 2.1 AA compliant, intentional friction

## 🏗️ Architecture

### Core Components
- **BaseControl3D** - Base class for all 3D controls
- **Scene3D** - 3D scene management
- **RoomManager** - Environment/room switching system
- **ControlCoordinator** - Coordinates Three.js controls (OrbitControls, TransformControls, DragControls)

### core Components (13)
1. 🔘 **Button3D** - 3D button with states and animations
2. 📝 **Input3D** - Text input in 3D space
3. 🔄 **Toggle3D** - Switch/toggle control
4. 🎚️ **Slider3D** - Range slider with 3D handle
5. 🪟 **Modal3D** - 3D dialog/modal overlay
6. 💡 **Tooltip3D** - Contextual help tooltips
7. 📋 **Accordion3D** - Collapsible content sections
8. 📄 **RichTextDisplay3D** - Rich text and markdown display
9. 🎡 **RadialMenu3D** - Spatial pie menu with Z-pop
10. 🧲 **MagneticCard3D** - Physics-based panel with parallax
11. 🌀 **PortalCard3D** - Dimensional window viewport
12. 📦 **VolumetricCard3D** - 3D model "pop-out" card
13. 😇 **HaloCard3D** - Smart billboard/HUD follow

### Phase 3: Generative Spatial UI
- 🌌 **AIPortal3D** - World-swapping gateway with Event Horizon shader
- 🧬 **LiquidUI** - Metaball-based organic controls (In Design)
- 👻 **SemanticGhost3D** - Contextual AI-generated help (In Design)

### Environments (Rooms)
- 📐 **CoordinateRoom** - 3D coordinate system background
- 🏔️ **LandscapeRoom** - Distant landscape background
- 🌌 **SpaceRoom** - Space with stars background
- 🧪 **MarsBaseRoom** - Immersive red planet environment
- 🌊 **LiquidEtherRoom** - Liquid ether animated background
