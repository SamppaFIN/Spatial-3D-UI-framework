📋 Accordion3D

Collapsible 3D accordion with multiple sections, markdown content support, and smooth expand/collapse animations. Perfect for organizing information in spatial interfaces.

Live Demo

✨ Drag to rotate • Scroll to zoom • Click sections to expand/collapse

Features

📂 Multiple Sections

Support for multiple collapsible sections with individual content.

🎬 Smooth Animations

Smooth expand/collapse animations with configurable speed.

📝 Markdown Support

Full markdown rendering for rich text content.

🎨 Three Geometry Modes

Choose between box, sphere, or sacred geometry.

🔄 Multi-Open Support

Multiple sections can be open simultaneously.

🎯 Event Callbacks

onItemToggle callback for custom logic.

Basic Usage

JavaScript
import { Scene3D } from './src/core/Scene3D.js';
import { Accordion3D } from './src/controls/Accordion3D.js';

const scene3D = new Scene3D(canvas);
const scene = scene3D.getScene();
const camera = scene3D.getCamera();
const renderer = scene3D.getRenderer();

const accordion = new Accordion3D(scene, camera, [0, 0, 0], {
    width: 5.0,
    itemHeight: 0.8,
    itemSpacing: 0.2,
    mode: 0,
    items: [
        {
            title: '📊 Section 1',
            contentHeight: 3.0,
            content: '# Content\\n\\nMarkdown **content** here.'
        },
        {
            title: '🎯 Section 2',
            contentHeight: 2.5,
            content: '# More Content\\n\\nAnother section.'
        }
    ],
    openItems: [0],
    renderer: renderer,
    onItemToggle: (accordion, index, isOpen) => {
        console.log(`Section ${index} ${isOpen ? 'opened' : 'closed'}`);
    }
});

function animate() {
    requestAnimationFrame(animate);
    accordion.update();
    scene3D.render();
}
animate();

API Reference

Constructor

new Accordion3D(scene, camera, position, options)

Options

Property Type Default Description
width number 5.0 Accordion width in 3D units
itemHeight number 0.8 Height of each section header
itemSpacing number 0.2 Spacing between sections
mode number 0 Geometry mode: 0=box, 1=sphere, 2=sacred
items array [] Array of section objects (see below)
openItems array [] Array of initially open section indices
renderer WebGLRenderer required Three.js renderer instance
onItemToggle function null Callback when section toggles (accordion, index, isOpen)

Item Object

Property Type Description
title string Section title text
contentHeight number Height of content when expanded
content string Markdown content to display

Methods

Method Description
update() Update accordion state (call in animation loop)
toggleItem(index) Toggle section at index
openItem(index) Open section at index
closeItem(index) Close section at index
dispose() Clean up resources
