Toggle3D API Reference

Property Type Default Description
isOn boolean false Current state of the toggle
onColor hex 0x4ecdc4 Color when active
offColor hex 0x444444 Color when inactive
trackShape string 'pill' pill, box, rounded, hexagon
trackMaterialType string 'glass' glass, metal, standard, matte
handleShape string 'sphere' sphere, box, hexagon
width number 2.2 Toggle total width
tension number 0.15 Spring stiffness (physics)
