🪟 Modal3D

Interactive 3D modal dialog with backdrop, smooth animations, and customizable content. Perfect for confirmations, forms, and important messages in spatial interfaces.

Live Demo

✨ Drag to rotate • Scroll to zoom • Click buttons to open modals

Features

🎬 Smooth Animations

Open/close animations with scale and opacity transitions.

🎭 Backdrop Overlay

Semi-transparent backdrop that closes modal when clicked.

❌ Close Button

Built-in close button with hover effects.

📝 HTML Content

Support for rich HTML content via overlay system.

🎨 Three Geometry Modes

Choose between box, sphere, or sacred geometry.

🎯 Event Callbacks

onOpen and onClose callbacks for custom logic.

Basic Usage

JavaScript
import { Scene3D } from './src/core/Scene3D.js';
import { Modal3D } from './src/controls/Modal3D.js';
import { Button3D } from './src/controls/Button3D.js';

const scene3D = new Scene3D(canvas);
const scene = scene3D.getScene();
const camera = scene3D.getCamera();
const renderer = scene3D.getRenderer();

// Create modal
const modal = new Modal3D(scene, camera, [0, 0, 2], {
    title: 'Confirm Action',
    width: 5.0,
    height: 4.0,
    mode: 0,
    isOpen: false,
    renderer: renderer,
    onOpen: (modal) => console.log('Modal opened'),
    onClose: (modal) => console.log('Modal closed')
});

// Create button to open modal
const openButton = new Button3D(scene, camera, [0, 0, 0], {
    label: 'Open Modal',
    renderer: renderer,
    onClick: () => modal.open()
});

function animate() {
    requestAnimationFrame(animate);
    modal.update();
    openButton.update();
    scene3D.render();
}
animate();

API Reference

Constructor

new Modal3D(scene, camera, position, options)

Options

Property Type Default Description
title string 'Modal' Modal title text
width number 6.0 Modal width in 3D units
height number 4.0 Modal height in 3D units
mode number 0 Geometry mode: 0=box, 1=sphere, 2=sacred
isOpen boolean false Initial open state
backgroundColor number 0x1a1a2e Background color (hex)
borderColor number 0x6bb6ff Border color (hex)
renderer WebGLRenderer required Three.js renderer instance
onOpen function null Callback when modal opens
onClose function null Callback when modal closes

Methods

Method Description
update() Update modal state (call in animation loop)
open() Open the modal
close() Close the modal
toggle() Toggle modal open/close state
isModalOpen() Check if modal is currently open
dispose() Clean up resources
