🚀 Getting Started

Learn how to create immersive 3D spatial interfaces with Spatial UI 3D in just a few minutes.

Installation

Spatial UI 3D is a lightweight library built on Three.js. You can get started in two ways:

1 Clone the Repository

Bash 
git clone https://github.com/SamppaFIN/Spatial-3D-UI-framework.git
cd spatial-ui-3d
npm install
npm start

2 Use CDN (Quickest)

For quick prototyping, use the CDN version with ES modules:

HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Spatial UI App</title>
    <style>
        body { margin: 0; overflow: hidden; }
        #canvas { width: 100vw; height: 100vh; display: block; }
    </style>
</head>
<body>
    <canvas id="canvas"></canvas>

    <!-- Three.js Import Map -->
    <script type="importmap">
    {
        "imports": {
            "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
            "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
        }
    }
    </script>

    <!-- Your app -->
    <script type="module" src="./app.js"></script>
</body>
</html>
💡 Note: Make sure to include the Three.js import map before your application code.

Quick Start

Create your first 3D button in less than 30 lines of code:

JavaScript 
// app.js
import { Scene3D } from './src/core/Scene3D.js';
import { Button3D } from './src/controls/Button3D.js';
import { ControlRegistry } from './src/core/ControlRegistry.js';

// Initialize 3D scene
const canvas = document.getElementById('canvas');
const scene3D = new Scene3D(canvas);
const scene = scene3D.getScene();
const camera = scene3D.getCamera();
const renderer = scene3D.getRenderer();
const orbitControls = scene3D.getControls();

// Initialize ControlRegistry
ControlRegistry.setOrbitControls(orbitControls);

// Create a 3D button
const button = new Button3D(scene, camera, [0, 0, 0], {
    label: 'Click Me!',
    width: 2.5,
    height: 1.0,
    mode: 0,
    renderer: renderer,
    onClick: (btn) => {
        console.log('Button clicked!');
        btn.setLabel('Clicked! ✓');
    }
});

// Animation loop
function animate() {
    requestAnimationFrame(animate);
    
    // Update all controls
    ControlRegistry.getAll().forEach(control => {
        if (control && control.update) {
            control.update();
        }
    });
    
    scene3D.render();
}

animate();
✅ Success! You now have a working 3D button. Try clicking it and dragging to rotate the view!

Basic Concepts

Scene3D

The Scene3D class manages your 3D environment, including the WebGL renderer, camera, lighting, and OrbitControls. 

const scene3D = new Scene3D(canvas);
const scene = scene3D.getScene();      // Three.js Scene
const camera = scene3D.getCamera();    // PerspectiveCamera
const renderer = scene3D.getRenderer(); // WebGLRenderer
const controls = scene3D.getControls(); // OrbitControls

ControlRegistry

The ControlRegistry manages all UI controls globally. It handles OrbitControls coordination and edit mode. 

// Initialize with OrbitControls
ControlRegistry.setOrbitControls(orbitControls);

// Get all controls
const allControls = ControlRegistry.getAll();

// Enable edit mode
ControlRegistry.setEditMode(true);

Component Lifecycle

All components follow a simple lifecycle:

  1. Create: Instantiate with new ComponentName()
  2. Update: Call component.update() in animation loop
  3. Dispose: Call component.dispose() when done

Creating Your First Component

Let's create a more complete example with multiple components:

JavaScript 
import { Scene3D } from './src/core/Scene3D.js';
import { Button3D } from './src/controls/Button3D.js';
import { Toggle3D } from './src/controls/Toggle3D.js';
import { TextDisplay3D } from './src/controls/TextDisplay3D.js';
import { ControlRegistry } from './src/core/ControlRegistry.js';

// Setup scene
const canvas = document.getElementById('canvas');
const scene3D = new Scene3D(canvas);
const scene = scene3D.getScene();
const camera = scene3D.getCamera();
const renderer = scene3D.getRenderer();

ControlRegistry.setOrbitControls(scene3D.getControls());

// Create a button
const saveButton = new Button3D(scene, camera, [-3, 0, 0], {
    label: 'Save',
    width: 2.0,
    height: 0.8,
    renderer: renderer,
    onClick: () => console.log('Saving...')
});

// Create a toggle
const darkModeToggle = new Toggle3D(scene, camera, [0, 0, 0], {
    label: 'Dark Mode',
    width: 2.5,
    height: 0.6,
    isOn: true,
    renderer: renderer,
    onClick: (toggle) => {
        console.log('Dark mode:', toggle.isOn);
    }
});

// Create a text display
const infoDisplay = new TextDisplay3D(scene, camera, [3, 0, 0], {
    content: '# Welcome!\\n\\nThis is a **3D UI** demo.',
    width: 3.0,
    height: 2.5,
    renderer: renderer
});

// Animation loop
function animate() {
    requestAnimationFrame(animate);
    
    ControlRegistry.getAll().forEach(control => {
        if (control && control.update) {
            control.update();
        }
    });
    
    scene3D.render();
}

animate();

Geometry Modes

All components support three geometry modes for different aesthetics:

📦 Box Mode (0)

Classic rectangular geometry. Clean, professional, and familiar.

mode: 0

🌟 Sphere Mode (1)

Rounded spherical geometry. Soft, organic, and friendly.

mode: 1

🔮 Sacred Mode (2)

Sacred geometry patterns. Unique, spiritual, and eye-catching.

mode: 2

You can change the mode dynamically:

button.setMode(1); // Switch to sphere mode

Adding Tooltips

Tooltips provide contextual help and support markdown formatting:

JavaScript 
const button = new Button3D(scene, camera, [0, 0, 0], {
    label: 'Save',
    renderer: renderer,
    tooltip: {
        content: '**Save** 💾\\n\\nSave your current work',
        position: 'top',    // 'top', 'bottom', 'left', 'right'
        offset: [0, 1.5, 0] // [x, y, z] offset
    }
});
💡 Tip: Use \\n for line breaks and markdown for formatting (**bold**, *italic*, `code`).

Edit Mode

Edit mode enables TransformControls for easy positioning during development:

JavaScript 
// Enable edit mode globally
ControlRegistry.setEditMode(true);

// Or create a toggle for it
const editToggle = new Toggle3D(scene, camera, [0, -3, 0], {
    label: 'Edit Mode',
    renderer: renderer,
    onClick: (toggle) => {
        ControlRegistry.setEditMode(toggle.isOn);
    }
});

In edit mode, click any component to see TransformControls. Use them to:

  • Translate: Press T or click the translate icon
  • Rotate: Press R or click the rotate icon
  • Scale: Press S or click the scale icon
⚠️ Important: Disable edit mode in production. It's meant for development only.
