📖 API Reference

Complete API documentation for all Spatial UI 3D classes, methods, and utilities.

🏗️ Core Classes

Scene3D

Main 3D scene manager that handles WebGL rendering, camera, and controls.

JavaScript
new Scene3D(canvas: HTMLCanvasElement)

Methods

Method Returns Description
getScene() THREE.Scene Get the Three.js scene
getCamera() THREE.PerspectiveCamera Get the camera
getRenderer() THREE.WebGLRenderer Get the renderer
getControls() OrbitControls Get OrbitControls
render() void Render the scene

BaseControl3D

Base class for all 3D controls. Provides common functionality like tooltips, edit mode, and raycasting.

JavaScript
class YourControl extends BaseControl3D {
    constructor(scene, camera, position, config) {
        super(scene, camera, position, config);
    }
}

Common Options

Property Type Description
renderer * WebGLRenderer Three.js renderer (required)
tooltip object Tooltip configuration
onClick function Click callback
onHover function Hover callback
onHoverEnd function Hover end callback

ControlRegistry

Global registry for managing all 3D controls and edit mode.

JavaScript
import { ControlRegistry } from './src/core/ControlRegistry.js';

// Set OrbitControls reference
ControlRegistry.setOrbitControls(orbitControls);

// Enable edit mode
ControlRegistry.setEditMode(true);

// Get all controls
const controls = ControlRegistry.getAll();

Static Methods

Method Description
setOrbitControls(controls) Set OrbitControls reference
setEditMode(enabled) Toggle edit mode for all controls
getEditMode() Check if edit mode is enabled
getAll() Get array of all registered controls

RoomManager

Manages 3D environment backgrounds (Coordinate, Landscape, Space rooms).

JavaScript
const roomManager = new RoomManager(scene, camera);
roomManager.initialize();
roomManager.switchRoom('space');

📝 Common Patterns

Animation Loop

JavaScript
function animate() {
    requestAnimationFrame(animate);
    
    // Update all controls
    ControlRegistry.getAll().forEach(control => {
        if (control && control.update) {
            control.update();
        }
        if (control && control.updateTooltipAndLabelPositions) {
            control.updateTooltipAndLabelPositions();
        }
    });
    
    scene3D.render();
}
animate();

Edit Mode

JavaScript
// Enable edit mode for all controls
ControlRegistry.setEditMode(true);

// Or use a toggle
const editToggle = new Toggle3D(scene, camera, [0, 0, 0], {
    label: 'Edit Mode',
    renderer: renderer,
    onClick: (toggle) => {
        ControlRegistry.setEditMode(toggle.isOn);
    }
});

Responsive Resize

JavaScript
window.addEventListener('resize', () => {
    const width = canvas.clientWidth;
    const height = canvas.clientHeight;
    camera.aspect = width / height;
    camera.updateProjectionMatrix();
    renderer.setSize(width, height);
});

💡 Best Practices

  • ✅ Always call update() in your animation loop
  • ✅ Set ControlRegistry.setOrbitControls() before creating controls
  • ✅ Use dispose() when removing controls to prevent memory leaks
  • ✅ Keep renderer reference consistent across all controls
  • ✅ Use tooltips to provide context and improve UX
  • ✅ Test with edit mode enabled during development
  • ✅ Handle window resize for responsive layouts
