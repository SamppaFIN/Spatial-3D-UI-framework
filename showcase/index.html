🌟 Why Spatial UI 3D?

🎨

Generative UI

AI-driven layout adaptation that intelligently organizes components in 3D space based on context and user behavior.

🗣️

Multimodal Interactions

Support for voice commands, gesture controls, and spatial interactions beyond traditional mouse and keyboard.

♿

Accessible Design

WCAG 2.1 AA compliant with intentional friction, calm design principles, and inclusive for all abilities.

⚡

High Performance

Optimized for 60 FPS with efficient rendering, frustum culling, and smart resource management.

🧩

8 Core Components

Complete set of UI controls: Button, Toggle, Slider, Input, Display, Modal, Accordion, and Chart.

🌌

Immersive Environments

Multiple room backgrounds including Coordinate Grid, Landscape, Space, and Liquid Ether animations.

🧩 Component Library

All components support three geometry modes (Box, Sphere, Sacred), tooltips, edit mode with TransformControls, and seamless integration.

🚀 Quick Start

JavaScript 
import { Scene3D } from './src/core/Scene3D.js';
import { Button3D } from './src/controls/Button3D.js';

// Initialize 3D scene
const canvas = document.getElementById('canvas');
const scene3D = new Scene3D(canvas);
const scene = scene3D.getScene();
const camera = scene3D.getCamera();
const renderer = scene3D.getRenderer();

// Create a 3D button
const button = new Button3D(scene, camera, [0, 0, 0], {
    label: 'Click Me!',
    width: 2.5,
    height: 1.0,
    mode: 0, // 0=box, 1=sphere, 2=sacred
    renderer: renderer,
    onClick: (btn) => {
        console.log('Button clicked!');
    }
});

// Animation loop
function animate() {
    requestAnimationFrame(animate);
    button.update();
    scene3D.render();
}
animate();
